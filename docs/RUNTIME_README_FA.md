# راهنمای اجرای RelayForge v3 روی Windows Server 2019

این بستهٔ اجرایی **تنها پس از کامپایل موفق روی ویندوز** تولید می‌شود و شامل RelayForge.exe، اسکریپت راه‌اندازی و این راهنماست. فایل‌های Python `.py` در ZIP اجرایی قرار نمی‌گیرند؛ با این حال جلوگیری مطلق از مهندسی معکوس حتی برای EXE کامپایل‌شده ممکن نیست. HTML و JavaScript داشبورد باید در مرورگر اجرا شوند و ذاتاً قابل مشاهده‌اند.

۱. فایل‌ها را به پوشه قابل‌نوشتن و ثابت، مثلاً `C:\RelayForge` منتقل کنید.

۲. یک‌بار `RelayForge.exe` را اجرا کنید. داشبورد: `http://127.0.0.1:8765`.

۳. کلید ورود اولیه: `C:\RelayForge\data\dashboard-key.txt` را فقط در مرورگر همان VPS وارد کنید. هرگز آن را عمومی نکنید.

۴. مبدأ را به یکی از دو روش تعیین کنید:
- BotFather: نام کانال و توکن ربات؛ ربات در کانال مبدأ ادمین باشد. **فقط پیام‌های جدید پس از اضافه‌شدن ربات/دریافت update**، نه آرشیو کامل.
- API ID + API Hash: از my.telegram.org؛ شماره و کد ورود را در داشبورد وارد کنید؛ حساب دسترسی قانونی داشته باشد. گزینه آرشیو برای پست‌های قبلی قابل استفاده است.

۵. مقصدها را جداگانه انتخاب کنید و توکن/شناسه کانال هرکدام را وارد نمایید. فاصله ارسال صفر=فوری؛ ۱۰۸۰۰ ثانیه=هر ۳ ساعت.

۶. برای اجرا مستقل از ریموت دسکتاپ، PowerShell را با دسترسی Administrator باز و `INSTALL_AUTO_START.ps1` را اجرا کنید. یک حساب اختصاصی دارای دسترسی نوشتن فقط در پوشه برنامه معرفی کنید. به‌جای حساب SYSTEM توصیه نمی‌شود. Task Scheduler: `Run whether user is logged on or not` و `At startup`.

۷. خطاهای ارسال در خود داشبورد و در `data\logs\relayforge.log` ثبت می‌شوند. پایگاه داده `data\relayforge.sqlite3` و پوشه رسانه و `data\telegram_user.session` باید پشتیبان‌گیری شوند. **تمام پوشه data را باهم پشتیبان بگیرید**؛ بدون `data\secrets.key` رمزگشایی توکن‌ها ممکن نیست.

۸. بعد از خاموش‌شدن یا قطع شبکه، وضعیت `uncertain` را بررسی کنید. «تلاش مجدد» ممکن است منجر به انتشار تکراری شود و باید آگاهانه انتخاب شود.

۹. دسترسی بیرونی: پورت 8765 را باز نکنید. پنل فقط localhost است و در RDP یا تونل امن SSH قابل مشاهده است.

۱۰. نسخه اجرایی روی Windows Server 2019 در این محیط (لینوکس) آزموده نشده است. قبل از استفاده در کانال اصلی، روی کانال آزمایشی با متن و رسانه هر سرویس تست واقعی انجام دهید.
