مقصدها و کلیدهای API

هر مقصد تنظیمات، صف، وضعیت و زمان‌بندی کاملاً مستقل دارد.

۵ پیام‌رسان قابل اتصالابتدا کلید API را وارد کن؛ سپس انتشار را فعال کن.

حذف، مقصد را بایگانی و پیام‌های در صف را رد می‌کند؛ تاریخچه باقی می‌ماند. ابتدا موتور را متوقف کنید. تست API فقط دسترسی را بررسی می‌کند؛ پیام آزمایشی واقعاً به کانال ارسال می‌شود.

مدیریت عملیات و داده‌ها

سوابق قبلی نگهداری می‌شوند. بازنشانی صرفاً عملیات تازه ایجاد می‌کند.

◈ پشتیبان پایگاه داده

پایگاه داده و کلید رمزگذاری ذخیره می‌شوند؛ فایل‌های رسانه، نشست تلگرام و کلید داشبورد را جداگانه با دسترسی محدود نگه دارید.

⚠ شروع عملیات جدید

ابتدا موتور را متوقف کنید. صف قدیمی بایگانی و مقصدها غیرفعال می‌شوند. پیام‌های منتشرشده حذف نمی‌شوند؛ ارسال مجدد ممکن است تکراری باشد.

◷ اجرای دائمی ویندوز

برای اجرای خودکار از اسکریپت INSTALL_AUTO_START.ps1 همراه بسته اجرایی و یک حساب اختصاصی کم‌اختیار استفاده کنید. پس از راه‌اندازی، موتور فقط اگر قبلاً از پنل شروع شده باشد ادامه می‌دهد. برای پروژه‌های جداگانه از START_PROJECT.bat استفاده کنید. گزینه اختیاری Windows Service در INSTALL_SERVICE_WINDOWS.ps1 است؛ فقط یکی از دو روش اجرا را نصب کنید.

Getting started

راهنمای راه‌اندازی

یک بار تنظیم کن؛ ربات مستقل از پنجره Remote Desktop کار خواهد کرد.

01

اتصال مبدأ

اگر فقط پست جدید می‌خواهی از BotFather استفاده کن. برای خواندن آرشیو گذشته API ID/Hash و حساب تلگرام لازم است.

02

انتخاب پیام‌رسان‌ها

توکن و شناسه کانال مقصد را برای هر پیام‌رسان وارد کن؛ فعال‌سازی هر مقصد مستقل است.

03

زمان‌بندی انتشار

فاصله صفر برای ارسال تقریباً فوری و ۱۸۰ دقیقه برای انتشار هر سه ساعت است.

04

اجرای خودکار در VPS

Windows Task Scheduler → At startup و Run whether user is logged on or not. از آرگومان --no-browser استفاده کن.

امنیت و محدودیت‌های واقعی

پنل فقط روی localhost فعال است. دسترسی راه دور را با تونل SSH امن انجام بده؛ پورت 8765 را مستقیماً روی اینترنت باز نکن. کلیدها در دیتابیس رمزگذاری می‌شوند، اما کلید رمزگذاری و جلسه تلگرام در همان VPS هستند و باید دسترسی NTFS محدود داشته باشند.

BotFather پیام‌های تاریخی کانال را فهرست نمی‌کند؛ آرشیو آن تنها کپی مستقیم به تلگرام است. محتوای دارای حفاظت کپی دور زده نمی‌شود. آلبوم‌ها ممکن است به‌صورت پیام مستقل منتشر شوند. در اولین راه‌اندازی، تست عملی متن و رسانه برای تک‌تک پیام‌رسان‌ها لازم است.
