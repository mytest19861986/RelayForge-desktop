# بسته ابزار ساخت EXE ویندوز — RelayForge 3.0

این بسته **فایل EXE کامپایل‌شده نیست**. برای اینکه انتشار نسخهٔ اجرایی بدون کد `.py` انجام شود، اول باید EXE واقعی روی ویندوز کامپایل شود. این ZIP ابزار ساخت، workflow و راهنما را دارد.

## گام‌ها

۱. ابتدا ZIP سورس RelayForge را در یک پوشه مانند `C:\RelayForgeSrc` استخراج کنید.
۲. فایل‌های این ZIP ابزار ساخت را روی همان پوشه کپی کنید (یا اگر از همان ZIP سورس استفاده می‌کنید، ابزارها از قبل در آن موجودند).
۳. روی Windows Server 2019/Windows 11 با Python 3.12 x64 فایل `BUILD_EXE_WINDOWS.bat` را اجرا کنید. دسترسی اینترنت و کامپایلر C لازم خواهد بود (Nuitka در صورت نیاز MinGW64 را دریافت می‌کند).
۴. در صورت عبور تست‌ها و کامپایل، فایل واقعی `build_output\RelayForge.exe` و بسته `RelayForge_v3.0.2_WINDOWS_EXE.zip` ساخته می‌شود. این بستهٔ خروجی شامل `.py` نیست؛ برای توزیع فقط همین ZIP واقعی را بفرستید.
۵. گزینه دوم: فایل workflow در `.github/workflows/build-windows.yml` را در مخزن PRIVATE خودتان اجرا کنید؛ خروجی Windows EXE را از Artifacts دانلود کنید. source/token/session را در مخزن عمومی قرار ندهید.

**محدودیت مهم:** Nuitka دسترسی به منطق سورس را سخت‌تر می‌کند، اما کد کامپایل‌شده صددرصد غیرقابل مهندسی معکوس نیست. HTML و JavaScript سمت مرورگر همواره قابل مشاهده‌اند؛ توکن‌ها داخل آن‌ها قرار ندارند.
