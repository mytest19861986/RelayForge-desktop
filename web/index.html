Getting started

راهنمای راه‌اندازی

یک بار تنظیم کن؛ ربات مستقل از پنجره Remote Desktop کار خواهد کرد.

01

اتصال مبدأ

اگر فقط پست جدید می‌خواهی از BotFather استفاده کن. برای خواندن آرشیو گذشته API ID/Hash و حساب تلگرام لازم است.

02

انتخاب پیام‌رسان‌ها

توکن و شناسه کانال مقصد را برای هر پیام‌رسان وارد کن؛ فعال‌سازی هر مقصد مستقل است.

03

زمان‌بندی انتشار

فاصله صفر برای ارسال تقریباً فوری و ۱۸۰ دقیقه برای انتشار هر سه ساعت است.

04

اجرای خودکار در VPS

Windows Task Scheduler → At startup و Run whether user is logged on or not. از آرگومان --no-browser استفاده کن.

امنیت و محدودیت‌های واقعی

پنل فقط روی localhost فعال است. دسترسی راه دور را با تونل SSH امن انجام بده؛ پورت 8765 را مستقیماً روی اینترنت باز نکن. کلیدها در دیتابیس رمزگذاری می‌شوند، اما کلید رمزگذاری و جلسه تلگرام در همان VPS هستند و باید دسترسی NTFS محدود داشته باشند.

BotFather پیام‌های تاریخی کانال را فهرست نمی‌کند. محتوای دارای حفاظت کپی دور زده نمی‌شود. آلبوم‌ها ممکن است به‌صورت پیام مستقل منتشر شوند. در اولین راه‌اندازی، تست عملی متن و رسانه برای تک‌تک پیام‌رسان‌ها لازم است.
