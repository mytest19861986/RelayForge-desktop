# بسته ساخت مستقل نسخه ۴
این ZIP ابزار ساخت EXE و سورس لازم را دارد؛ EXE کامپایل‌شده ندارد. Python 3.12 x64 را نصب و BUILD_EXE_WINDOWS.bat اجرا کنید. اسکریپت با venv جدا، تست‌ها، Nuitka و smoke HTTP خود باینری، ZIP اجرایی را در صورت موفقیت ایجاد می‌کند. کد Python به شخص ثالث ندهید؛ فقط ZIP اجرایی ساخته‌شده را تحویل دهید. مسیرهای داده قبلی را بازنویسی نکنید.
